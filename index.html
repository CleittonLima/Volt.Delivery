VOLT.DELIVERY

Versão: BETA V1.0

Desenvolvedor: Erisvaldo Cleiton

Descrição: Volt.Delivery é um jogo educacional focado no desenvolvimento do raciocínio lógico e na introdução aos conceitos de programação visual. O jogador deve criar algoritmos passo a passo para guiar o robô por labirintos desafiadores, otimizando rotas para alcançar as três estrelas, gerenciando inteligentemente o consumo de bateria persistente e calculando o tempo exato para desviar dos inimigos.

Projetado para ensinar fundamentos da computação de forma interativa, visual e imersiva!
